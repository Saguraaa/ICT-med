## 5. 数字计算口径

- 正确率相对提升 = (候选正确率 - 基线正确率) / 基线正确率 × 100%。
- 百分点变化 = (候选正确率 - 基线正确率) × 100。
- token/延迟/费用降低率 = (基线值 - 候选值) / 基线值 × 100%。
- 使用相同病例配对、按病例聚类 bootstrap；重跑不视作新增患者。失败不删除。
- 采用的统计方法、重采样种子、CI 和样本量充分性必须列出。推断多个单项收益时报告多重比较处理（建议 Holm 校正的配对检验），区分探索性与确认性结论。
- 缺模型 token 用量不填零；模型自评不能替代独立医学标签。

## 6. 失败分析与结论

至少覆盖：错误紧急程度、错误专家意见被采纳、检索无效/不适用、重要事实遗漏、预算耗尽、过度转人工。使用去标识案例 ID 与结构化说明。

## 重跑

在 med 目录、已安装 requirements.txt 的 Python 3.12 环境中：

```bash
python -m unittest discover -s tests -v
```

只测试标准库核心时，无需 SDK；三项 SDK 测试会明确跳过。完整报告必须确认没有跳过。

演示评测：设置 `MODEL_BACKEND=demo`，执行 `python evaluation.py`。合成案例成绩只能说明程序按标记走到预期分支，不能作为医疗性能结果。
